Methods

Grading rules, overlap thresholds and search queries, versioned with each release. Build 2026-09-22T00:00:00Z.

Evidence tiers

TierCodeDefinition
DirectT1A GWAS, exome or candidate study measured this exact phenotype.
Related phenotypeT2The association is for a phenotype linked to the target in the phenotype-relationship table.
Mechanistic / functionalT3The variant or gene affects expression, protein level or immune function, with no phenotype association to the target.

Display grade

Computed in code (genetics_pipeline/grading.py), never curated by hand:

  • A = T1, genome-wide significant (p < 5×10⁻⁸), replicated in an independent cohort
  • B = T1, genome-wide significant, unreplicated
  • C = T1 suggestive (5×10⁻⁸ > p ≥ 1×10⁻⁵), or any T2
  • D = T3 only

A tested_null result records absence of evidence and carries no letter grade.

Overlap definitions

  • Shared locus: credible sets overlap, or colocalisation posterior (H4) ≥ 0.8 where available. Without either, lead variants in LD r² ≥ 0.5 in a matched ancestry panel. Physical proximity alone is labelled "nearby", not "shared". This build uses neither credible sets nor LD — locus rows are ±50kb distance windows around each lead variant pending Open Targets ingestion.
  • Shared gene: L2G score ≥ 0.5 in both phenotypes, or one L2G ≥ 0.5 plus a QTL for the same gene. This build has no L2G scores yet (distance-window fallback only).
  • Shared pathway: ≥2 genes from a pathway each implicated at the gene level in both phenotypes; descriptive overlap only. Not populated in this build (module 5).

Known gaps in this build

  • Open Targets Platform bulk Parquet ingestion (module 4 credible sets, L2G scores, colocalisation) — locus-to-gene assignment in this build uses the spec's documented distance-window fallback only
  • eQTL Catalogue bulk files (module 4 QTL layer) — no molecular_qtls records in this build
  • Reactome/GO pathway membership (module 5) — no pathways records in this build
  • IEU OpenGWAS PheWAS-style lookups — requires an API token (see build spec open question)
  • HLA allele support (IPD-IMGT/HLA nomenclature) — no HLA-typed associations ingested yet; vaccine-reactogenicity and post-vaccination-myocarditis phenotypes remain not_searched
  • Pinned HPO release for phenotypes.hpo_ids — left blank pending the same pinned release used by the PAIS cohort database
