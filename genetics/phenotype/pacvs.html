Related phenotypes

Why evidence from these phenotypes is surfaced here:

  • Long COVID / PASC (symptom overlap)
    PACVS and Long COVID share a core post-acute symptom cluster (fatigue, cognitive impairment, autonomic dysfunction) following an immune-activating exposure (vaccination vs. infection); a 2023 comparative review found overlapping but distinct symptom profiles. FOXP4 T2 evidence is surfaced on this basis, not as PACVS-specific evidence. [PMID:37192595]
  • ME/CFS (clinical overlap)
    PACVS case series report post-exertional malaise, unrefreshing sleep and cognitive dysfunction that overlap substantially with ME/CFS diagnostic criteria, motivating use of ME/CFS genetic findings as T2 context pending PACVS-specific studies.
  • POTS / dysautonomia (clinical overlap)
    Autonomic/dysautonomia features (orthostatic intolerance, tachycardia) co-occur frequently in PACVS case series; POTS genetic findings are surfaced as T2 context.
  • Vaccine reactogenicity (shared exposure) gap — not yet searched
    PACVS follows the same exposure (COVID-19 vaccination) as reactogenicity phenotypes; HLA-linked reactogenicity findings are a mechanistic candidate for PACVS, not direct evidence. Relationship recorded ahead of the vaccine-reactogenicity literature sweep (not_searched).
  • Post-vaccination myocarditis (shared exposure) gap — not yet searched
    Shares vaccination exposure and a suspected immune-mediated mechanism with PACVS; included as a T2 candidate source ahead of the post-vaccination-myocarditis literature sweep (not_searched).

Evidence map

PACVS → related phenotypes → shared loci → genes. Gap nodes mark related phenotypes with no data yet.

What would close this gap

  • A GWAS or candidate-gene study using a PACVS-specific case definition (none exists as of 2026-09-22).
  • HLA typing in PACVS cohorts, given HLA associations already reported for vaccine reactogenicity and myocarditis.
  • Targeted lookups of the Long COVID FOXP4 locus and other T2 loci in any future PACVS cohort with genotype data.

Case-definition compatibility

No source study in this build used a PACVS-specific case definition. T2 evidence is annotated with the originating study's own case definition (see the Studies table above) so a reader can judge compatibility with whichever PACVS definition they are working from — this build does not pick one as reference (see the build's open questions).
