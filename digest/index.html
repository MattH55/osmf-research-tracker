How the digest is built

A script (scripts/build_digest.py) runs after the daily PubMed and ClinicalTrials.gov refresh. It takes every study whose publication date falls in the last seven days from each condition feed, de-duplicates by PMID, and lists trials whose registry record changed in the same window. When fewer than three new studies are found the window is widened to fourteen days and the issue says so. Each issue is frozen as a JSON snapshot once its week has passed. Nothing is written by hand; errors in titles or abstracts come from the source records.

Annual, per-condition summaries live in the state-of-the-evidence reports.
